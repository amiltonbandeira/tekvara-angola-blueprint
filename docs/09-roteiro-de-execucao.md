# Roteiro de execução

## Fase 0 — Preparar (agora)

- [ ] Rever este blueprint;
- [ ] Confirmar segmento prioritário;
- [ ] Criar lista de 30 potenciais entrevistados;
- [ ] Corrigir contactos demonstrativos do website quando existirem os reais;
- [ ] Criar uma folha privada de pipeline.

## Fase 1 — Validar (semanas 1–2)

- [ ] Fazer 10–15 entrevistas;
- [ ] Identificar um problema recorrente;
- [ ] Escolher uma oferta-piloto;
- [ ] Enviar pelo menos 3 propostas;
- [ ] Registar objeções e ajustar a oferta.

## Fase 2 — Vender e entregar (semanas 3–6)

- [ ] Fechar o primeiro piloto pago;
- [ ] Usar proposta e contrato;
- [ ] Entregar em marcos;
- [ ] Recolher aceite e testemunho;
- [ ] Calcular margem real.

## Fase 3 — Formalizar com clareza (em paralelo, quando houver decisão)

- [ ] Confirmar nome e objeto social;
- [ ] Falar com contabilista certificado;
- [ ] Confirmar processo e custos no GUE;
- [ ] Tratar NIF, licenciamento e conta empresarial conforme orientação;
- [ ] Rever contratos e proteção de dados.

## Fase 4 — Repetir e melhorar (dias 60–90)

- [ ] Transformar o primeiro resultado em estudo de caso;
- [ ] Repetir a prospecção semanal;
- [ ] Criar manutenção ou suporte recorrente;
- [ ] Documentar tarefas repetidas;
- [ ] Decidir se é altura de criar um produto próprio.

## Regra de decisão

Se não houver entrevistas, não criar produto. Se não houver propostas aceites, rever oferta. Se houver vendas mas não houver margem, rever preço e escopo. Se houver procura consistente, investir gradualmente em capacidade.
