# Modelo financeiro inicial

## Princípios

- Separar dinheiro pessoal e dinheiro da empresa assim que for possível;
- Registar todas as entradas e saídas;
- Não confundir faturação com lucro;
- Reservar dinheiro para impostos, custos e períodos sem vendas;
- Não comprar ferramentas antes de saber que são necessárias.

## Estrutura mensal

| Categoria | Exemplos |
| --- | --- |
| Receita | Projetos, consultoria, manutenção |
| Custos diretos | Domínio, alojamento, APIs, freelancers |
| Custos fixos | Internet, software, contabilidade, banco |
| Reserva | Impostos, emergências, reinvestimento |
| Resultado | Receita - custos diretos - custos fixos - reserva |

## Cálculo de preço

Preço mínimo de projeto = (horas estimadas × valor-hora mínimo) + custos diretos + margem de risco.

O valor-hora mínimo deve cobrir tempo não faturável, vendas, administração, aprendizagem, impostos e períodos sem projetos. Rever com contabilista.

## Meta dos primeiros 90 dias

- Validar uma oferta;
- Fechar pelo menos um projeto pago;
- Reinvestir apenas no que ajuda a vender ou entregar;
- Criar uma reserva inicial;
- Medir margem real de cada projeto.
